01 — Overview

Project Overview

Live at predatorfest.com

Predator Fest League (PFL) is a fishing competition league I co-founded in Lviv. Every second tournament had the same problem — results scribbled on a piece of paper during the event, photos shared in chats, scores miscounted, standings nowhere to be found a week later.

I built the PFL App from scratch — a Telegram Mini App (and PWA) that gives every participant instant access to live results, tournament standings, a season leaderboard, and partner information. All data updates in real time directly from a Google Sheet. No backend, no database, no overhead.

The app has been live across multiple seasons, tracked 80+ participants across tournaments, and helped the community raise 64,375 UAH for Ukraine's armed forces through competition entry fees.

🇺🇦 64,375 UAH raised for the Armed Forces of Ukraine across all events
02 — Problem

The Problem I Kept Running Into

After moving to Lviv and getting seriously into competitive spin fishing, I noticed the same friction at almost every tournament. The system "worked" — but just barely, and only for the organiser who scribbled it all down.

Scores were written by hand on paper at the weigh-in, then photographed and dropped into a Telegram chat. If you missed the photo or the chat was busy, you'd never find your result. Rankings were calculated manually in Google Sheets — which was better than paper, but still invisible to anyone except the organiser.

This is the kind of problem that's very familiar to anyone who works in product: the system technically works, but using it is genuinely uncomfortable.

Root insight
Results existed — they just lived in the wrong place. The fix wasn't a new data model, it was a better interface over the data that already existed.

03 — Solution

Why a Telegram Mini App?

The audience — local fishing community — lives in Telegram. A native iOS/Android app would mean an App Store submission, installs, updates, and a completely separate context. A Telegram Mini App opens with one tap inside a chat they already use every day, and feels native on mobile without any installation friction.

The choice was about meeting users where they already are — a core UX principle — while keeping the architecture dead simple so I could build and maintain it solo.

05 — Product Complexity

The Scoring System Behind the App

One of the real UX challenges was making a genuinely complex scoring model feel transparent and simple. The PFL season uses placement-based points across 6 events, with multiple bonus point categories and a tiebreaker chain. Getting this wrong in the UI — or the underlying formulas — destroys trust with competitors.

06 — Technology

Built Solo, Built to Last

The entire app was designed, built, and deployed by me — a product designer who used AI-assisted development tools to go from idea to production without a dedicated engineering team. This was a deliberate experiment in what a designer can ship independently in 2024.

📊
Google Sheets
The "database". Organisers use it like a familiar spreadsheet — no new tools, zero training, zero errors from manual re-entry.
⚙️
Google Apps Script
Acts as a lightweight API layer. Reads the sheet, applies scoring formulas, returns clean JSON to the front-end.
⚡️
Vanilla JS
No framework, no build step. Fast initial load inside Telegram's Mini App webview — critical for mobile performance.
🐙
GitHub + CI/CD
Staging and production branches. Automated deploys on push — the same workflow used in professional product teams.
✈️
Telegram Mini App
Native Telegram integration. Opens in one tap from the community channel — no install, no app store, no friction.
🌐
Progressive Web App
Also accessible as a full web app at predatorfest.com — same codebase, works on any device or browser.
